# 🎬 Google Vids 台本自動注入くん (全自動アップデート版)

YouTube AIブレーンチームが作成した動画台本を、**Google Vids** のナレーション・スクリプト入力欄に、スライドを自動で増やしながら全自動で流し込むChrome拡張機能です。

---

## 🛠️ Chromeへのインストール手順 (簡単3ステップ)

受け取った方が初めてインストールする際の手順です。

1. **Google Chrome** を開き、アドレスバーに以下を入力してEnterを押します：
   ```
   chrome://extensions/
   ```
2. 画面右上にある **「デベロッパーモード」** のスイッチを **ON** にします。
3. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** ボタンを押し、解凍したフォルダ `google-vids-script-injector` を選択します。

---

## 🚀 使い方

### モードA: プリセットから手動で流し込む
1. **Google Vids** の動画編集画面を開きます。
2. 拡張機能のアイコンから「台本自動注入くん」を開きます。
3. リストから「昭和AI ep4」等のシーンを選び、**「⚡ このシーンの台本を流し込む！」** ボタンを押します。
4. 対象シーンのナレーション欄に文字が入力されます。（※入力欄が閉じている場合は、クリップボードに自動コピーされるので Ctrl + V で貼り付け可能です）

### モードB: 自由な台本を【全自動】で流し込む (シーン自動追加対応) ★超おすすめ
1. **Google Vidsで、スライドが1つだけ（初期状態）のプロジェクトを開きます。**
2. モード選択で **「✍️ カスタム台本を入力して全自動で流し込む」** を選びます。
3. 下記の【台本の推奨フォーマット】のルールに従って作成した台本テキストを、テキストエリアに貼り付けます。
4. **「⚡ Google Vidsへ全自動流し込み！」** ボタンを1回押します。
5. **完了！** プログラムが自動でスライドを必要な数まで増やし、シーン1から順番に自動でナレーションをすべて入力していきます。（入力中はマウスやキーボード操作をせずにお待ちください）

---

## 📝 台本の推奨フォーマット

全自動流し込み（モードB）を使用する際は、メモ帳やChatGPT等で以下のルールに従って台本を作成してください。

* 各シーンの区切りに **`【シーン番号】タイトル`** という目印をつけます。
* 本文中の間の取りたい部分に、Google Vids用の制御タグ **`[pause 1.5s]`** などをそのまま記述します。

### 記述例：
```text
【シーン1】オープニング
皆さん、こんにちは。昭和AIです。[pause 1.5s]
本日はAI時代に必要な現場の知恵についてお話しします。[pause 2.0s]

【シーン2】歴史の教訓
100年前、電気モーターが登場した時も、工場の仕組みを変えなかった企業は生産性が上がりませんでした。[pause 2.5s]
```
